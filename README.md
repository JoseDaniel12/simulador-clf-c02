# Simulador CLF-C02

Simulador de práctica para el examen **AWS Certified Cloud Practitioner (CLF-C02)**, en español: 640 preguntas originales (por capítulo, por dominio y 6 simulacros completos de 65), modo estudio y modo examen, repetición espaciada y seguimiento del avance por tarea oficial.

Ábrelo en https://josedaniel12.github.io/simulador-clf-c02/ y, en el celular, usa «Agregar a pantalla de inicio» para tenerlo como app. El progreso se guarda en el navegador de cada dispositivo; para pasarlo de uno a otro, usa *Ajustes → Copia de tu progreso*.

Material de estudio independiente; no está afiliado a Amazon Web Services.
